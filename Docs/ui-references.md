# LingoFloat UI references

Verified 2026-09-11. These are interaction references, not sources for copied
logos, artwork, or branding.

- [Scribe](https://github.com/itchat/Scribe): native macOS toolbar and Inspector
  pattern; operational controls stay out of the transcript canvas.
- [Aiko](https://sindresorhus.com/aiko): transcription content receives nearly
  all of the window's visual emphasis.
- [SubtitleOverlay](https://github.com/SweelLong/SubtitleOverlay): an always-on-top
  subtitle panel where older lines fade and the newest line is dominant.
- [AirTranslate](https://github.com/himomohi/AirTranslate): system-audio capture,
  translation, and floating captions are presented as one focused workflow.

## Applied direction

- Compact native controller rather than a messenger-style main window.
- One current caption is visually dominant; source text becomes secondary when
  a translation is available.
- Start/Stop, language route, system-audio activity, installed model state, and
  the floating-overlay switch remain visible without opening Settings.
- Transcript history is still available, but it is no longer the visual center
  of the watch-a-video workflow.
